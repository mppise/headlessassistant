Theming

Customize the widget's appearance to match your portal's brand — colors, fonts, header text, and more.

What theming does

HeadlessAssistant exposes a theme config object that controls the visual appearance of the entire widget. All theme values are applied as CSS custom properties (--ha-*) on the widget's root element, so they can also be overridden from your own stylesheet if needed.

Theme options

FieldTypeDefaultWhat it controls
primary_colorCSS color #4F46E5 Button backgrounds, user message bubbles, header background, focus rings
background_colorCSS color #FFFFFF Chat panel background
font_familystring system-ui, sans-serif Font family applied to all widget text
font_sizeCSS size 14px Base font size for all widget text
header_titlestring "Assistant" Text displayed in the widget header bar
placeholder_textstring "Type a message…" Placeholder text in the message input field
avatar_urlURL or null null URL to an image used as the assistant's avatar. If null, a colored circle with "A" is shown
border_radiusCSS size 12px Border radius applied to the panel and message bubbles

Example

HeadlessAssistant.init({ ai_endpoint: 'https://your-api.example.com/chat', bearer_token: 'your-token', theme: { primary_color: '#0ea5e9', // sky blue background_color: '#f8fafc', font_family: '"Inter", system-ui, sans-serif', font_size: '15px', header_title: 'Support Chat', placeholder_text: 'How can we help?', avatar_url: 'https://your-cdn.example.com/support-avatar.png', border_radius: '8px' } });

CSS custom properties

All theme values are exposed as --ha-* CSS custom properties on the .ha-widget element. You can override them from your own stylesheet for fine-grained control without touching the config:

/* In your portal's stylesheet */ #ha-widget-root { --ha-primary-color: #0ea5e9; --ha-border-radius: 6px; --ha-font-size: 13px; }
CSS propertyMaps to config field
--ha-primary-colortheme.primary_color
--ha-background-colortheme.background_color
--ha-font-familytheme.font_family
--ha-font-sizetheme.font_size
--ha-border-radiustheme.border_radius
--ha-bubble-user-bgderived from --ha-primary-color
--ha-bubble-assistant-bg#F3F4F6 (fixed default)
--ha-text-color#111827 (fixed default)
--ha-header-bgderived from --ha-primary-color
CSS custom property overrides in your stylesheet take precedence over values set by the config. Use this to fine-tune styles that are not exposed as config options, such as --ha-bubble-assistant-bg or --ha-text-color.
