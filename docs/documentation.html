HeadlessAssistant — Demo

Live demo of the HeadlessAssistant embeddable chat widget. The floating bubble in the bottom-right corner is active on this page — click it to start a conversation.

Security notice: The bearer_token in your config is visible to anyone who can inspect the page source. Always use a short-lived, scoped token generated server-side — never a long-lived API master key.
Live · Floating bubble

Floating bubble mode

The widget is active on this page. Click the chat bubble in the bottom-right corner to open it. Responses are served by a local mock that streams markdown content with simulated 40ms chunk delays.

💡 Try sending a few messages to see SSE streaming, markdown rendering, and conversation history in action. Refresh the page — your history is preserved in localStorage.
// Auto-init via data-config attribute (drop-in script tag) <script src="/src/headless-assistant.js" data-config="/config/headless-assistant.config.json"> </script> // — or — Manual init HeadlessAssistant.init({ ai_endpoint: 'https://your-api.example.com/chat', bearer_token: 'your-short-lived-scoped-token', stream_mode: 'sse', theme: { header_title: 'My Assistant' } });
Code reference · Inline embed

Inline embed mode

Mount the widget inside a specific container element by passing a container CSS selector. The widget fills the container and is visible immediately — no bubble. Note: only one widget instance can be active per page at a time.

<div id="my-assistant" style="width:420px;height:520px;"></div> <script src="/src/headless-assistant.js"></script> <script> HeadlessAssistant.init({ ai_endpoint: 'https://your-api.example.com/chat', bearer_token: 'your-short-lived-scoped-token', container: '#my-assistant', max_turns: 10, stream_mode: 'sse', theme: { primary_color: '#4F46E5', header_title: 'My Assistant', placeholder_text: 'Ask me anything…' } }); </script>
